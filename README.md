# pizzalious-capstone2
Hello! My name is Jayln Ramos and this is my second capstone project for LTCA. I was asked to build a store's pos application, and here is how it works.

Project Description
Pizza-licious is growing fast and needs to move off paper orders. This application replaces the manual order process with a console based point of sale system that lets staff take fully customized pizza orders, add drinks and garlic knots, display a full order summary with pricing, and save a timestamped receipt file for every completed order.

Features
- New Order flow — staff create an order and add items one at a time
- Pizza customization — choose size (8", 12", 16"), crust type (thin / regular / thick / cauliflower), sauces, regular toppings, meat and cheese premium toppings (with extras), and optional stuffed crust
- Drinks — small / medium / large with flavor selection
- Garlic knots — add to any order
- Order validation — orders with 0 pizzas require at least a garlic knots or drink
- Checkout screen — full order summary with itemized pricing and a grand total
- Receipt files — saved to a receipts/ folder, named by timestamp (yyyyMMdd-hhmmss.txt)
- Runs until exited — the application loops back to the home screen after each order

Project Board (User Stories) 
- As a staff member, I can start a new order so that I can take a customer's order
- As a staff member, I can add a customized pizza to an order so that the customer gets exactly what they want
- As a staff member, I can view the order total at checkout so that I can tell the customer the price
- As a staff member, I can confirm an order and generate a receipt file so that there is a record of the transaction
